# OilRisk-Alert 项目启动指南

## 项目架构

```
前端 (Vue 3 + Vite)        → localhost:5173
  ↓ /api 代理
后端 (Spring Boot 4.0)     → localhost:8080
  ↓ HTTP 调用
Python 推理引擎 (FastAPI)  → localhost:5000
  ↓ 加载
模型文件 (OilRisk_System/) + 数据文件 (data/)
```

## 环境要求

| 组件 | 版本要求 |
|------|----------|
| Java | 17+ |
| Maven | 3.8+ |
| Node.js | 18+ |
| Python | 3.10 - 3.13 |
| MySQL | 8.0+ |

## 启动顺序

**必须按以下顺序启动，后端依赖 Python 引擎和数据库。**

---

### 第 1 步：MySQL 数据库

1. 确保 MySQL 服务已启动
2. 创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS oilrisk
  DEFAULT CHARACTER SET utf8mb4
  COLLATE utf8mb4_unicode_ci;
```

3. 数据库连接信息（见 `application.properties`）：
   - 地址：`localhost:3306`
   - 数据库名：`oilrisk`
   - 用户名：`root`
   - 密码：`123456`

> 表结构由 Spring Boot 自动执行 `schema.sql` 创建，无需手动导入。

---

### 第 2 步：Python 推理引擎（端口 5000）

```bash
cd C:\Users\asus\Desktop\OilRisk_Alert\python_engine

# 安装依赖（注意使用 Python 3.13 的完整路径，避免与 Anaconda 冲突）
C:\Users\asus\AppData\Local\Programs\Python\Python313\python.exe -m pip install -r requirements.txt

# 启动服务
C:\Users\asus\AppData\Local\Programs\Python\Python313\python.exe -m uvicorn app:app --host 0.0.0.0 --port 5000
```

验证：浏览器访问 http://localhost:5000/health ，返回 `{"status":"ok","models_loaded":true}` 即成功。

**依赖文件（必须存在）：**
- `OilRisk_System/` — 模型文件（best_lstm.pt, xgb_wti_shock_model.pkl 等）
- `data/Final_Oil_Dataset_Cleaned.csv` — 原始数据集

---

### 第 3 步：Spring Boot 后端（端口 8080）

```bash
cd C:\Users\asus\Desktop\OilRisk_Alert

# 方式一：Maven 命令行
mvnw spring-boot:run

# 方式二：IDEA 中直接运行主类
# 运行 com.example.oilrisk_alert.OilRiskAlertApplication
```

验证：浏览器访问 http://localhost:8080/api/risk/overview ，有 JSON 返回即成功。

**关键配置（`src/main/resources/application.properties`）：**

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `server.port` | 8080 | 后端端口 |
| `python.engine.url` | http://localhost:5000 | Python 引擎地址 |
| `llm.api.key` | （需填写） | DeepSeek API Key，用于 AI 报告生成 |

---

### 第 4 步：前端开发服务器（端口 5173）

```bash
cd C:\Users\asus\Desktop\OilRisk_Alert\frontend

# 启动开发服务器
```

访问：http://localhost:5173

> 前端通过 Vite 代理将 `/api` 请求转发到 `localhost:8080`。

## 常见问题

### pip install 报错找不到 fastapi

`pip` 指向了 Anaconda 旧版 Python。使用 Python 3.13 完整路径：

```bash
C:\Users\asus\AppData\Local\Programs\Python\Python313\python.exe -m pip install -r requirements.txt
```

### Python 引擎 500 错误

查看 Python 终端窗口的 traceback 日志，常见原因：
- 模型文件缺失 → 检查 `OilRisk_System/` 目录
- 数据文件缺失 → 检查 `data/Final_Oil_Dataset_Cleaned.csv`
- PyTorch 版本不兼容 → 确保 torch >= 2.5.0

### 后端报 Connection refused (502)

Python 引擎未启动或端口不对。确认 http://localhost:5000/health 可访问。

### 前端页面空白

确认后端已启动，浏览器 F12 查看 Network 是否有 API 请求失败。
