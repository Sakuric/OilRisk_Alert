## 八、架构设计

### 数据流

```
用户点击 TopBar "AI" 按钮
    → LlmConfigModal 弹窗
    → GET /api/config/llm（加载当前配置）
    → 修改后 PUT /api/config/llm（动态更新，立即生效）

用户点击 RiskOverview "生成AI摘要" 按钮
    → EventSource → GET /api/risk/ai-summary (SSE)
    → ReportServiceImpl.generateAiSummary()
        → RiskMapper.findLatest()（最新风险指数）
        → FactorMapper.findTopByDateOrderByAbsShap()（Top 5 因子）
        → 组装 prompt（风险指数 + 等级 + 油价 + Top5 因子 SHAP 值）
        → callLlmStreaming() → POST apis.iflow.cn/v1/chat/completions (stream=true)
    → 逐 token SSE 推送回前端（{token: "..."} 格式）
    → 前端实时追加到 displayedAiSummary
    → 收到 [DONE] 信号 → 生成完成
```

### 配置可切换性

LLM 配置存储在 Spring Bean 内存中（`LlmConfig @Component`），初始值从 `application.properties` 加载。通过 REST API 动态更新后立即生效，无需重启服务。支持任何 OpenAI 兼容的 `/v1/chat/completions` 接口。
