# OilRisk_Alert ML 模型集成 — 团队工作总结

## 项目概述

将 `OilRisk_System/` 中的三个 ML 模型（LSTM 趋势预测、XGBoost 冲击检测、Stacking Ridge 集成元学习器）集成到 OilRisk_Alert Web 应用中，完全替换后端伪随机数据，实现真实模型推理与展示。

**团队规模**：5 人（PM、后端开发、前端开发、测试、Bug 修复）

**技术栈**：Python FastAPI + Spring Boot 4 + Vue 3 + TypeScript + ECharts + MySQL
