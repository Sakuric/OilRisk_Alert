# OilRisk-Alert 模型系统简介

## 系统定位

基于 **Stacking 集成学习** 的原油价格风险预测系统，采用"双专家 + 元学习器"的两层架构，融合趋势信号与冲击信号，输出未来 5 个交易日的风险评估。

## 第1层：LSTM 趋势专家

| 项目 | 说明 |
|------|------|
| **文件** | `LSTM.py` |
| **模型权重** | `best_lstm.pt` (PyTorch) / `best_lstm.keras` (TensorFlow) |
| **任务** | 预测 5 个交易日后的 WTI 收盘价与涨跌方向 |
| **框架** | 自动检测 TensorFlow/PyTorch，当前部署使用 PyTorch |

### 特征体系 (27维)

| 类别 | 特征 | 说明 |
|------|------|------|
| 价格 | `price` | WTI 当前价格 |
| 日频金融 | `crb, sp500, tips, hy, vix, ovx, cushing` | CRB指数、标普500、通胀预期、高收益利差、VIX、OVX、库欣库存 |
| 月频变化量 | `opec_chg, saudi_chg, russia_chg, cn_pmi_chg, eu_pmi_chg, us_sentiment_chg` | 月度差分消除趋势伪相关 |
| 均线技术 | `ma5/20/60, dev_ma5/20/60` | 均线值及偏离率 |
| 动量波动 | `mom5, mom20, hvol20, cushing_chg5` | 对数动量、20日历史波动率、库存变化 |
| 方向性 | `mom_accel, vix_chg3, ovx_chg3` | 动量加速度、VIX/OVX 3日变化率 |

### 网络结构

```
Input (30天 × 27维)
  → LSTM(128) → BatchNorm
  → LSTM(64)  → BatchNorm → Dropout(0.2)
  ├── 价格头: Dense(32, ReLU) → Dense(1, Linear)     → 预测价格
  └── 分类头: Dense(16, ReLU) → Dense(1, Sigmoid)     → 上涨概率
```

### 关键训练配置

| 参数 | 值 | 说明 |
|------|-----|------|
| Lookback | 30 天 | 输入窗口长度（约6周） |
| Horizon | 5 天 | 预测时间跨度（约1周） |
| Loss | Huber + 0.5×BCE | 价格回归 + 方向分类联合训练 |
| 优化器 | Adam, lr=5e-4 | 配合 ReduceLROnPlateau |
| 早停 | patience=30 | 基于 val_loss |
| 缩放器 | RobustScaler | 对特征和价格分别缩放 |
| 数据切分 | 70/15/15 | 严格时序，不打乱 |

### 关键设计决策

- **分类权重 0.5** 是经过实验验证的平衡点：权重 1.0 导致 BCE 主导训练，val_loss 从 0.34 飙升至 0.89；权重 0.1 导致分类头退化（准确率≈50%）
- **双头独立隐层**：价格头和分类头各自有独立的 FC 隐层，避免争抢共享表示

## 第1层：XGBoost 冲击专家

| 项目 | 说明 |
|------|------|
| **文件** | `Xgboost_model1.py` |
| **模型权重** | `xgb_wti_shock_model.pkl` |
| **任务** | 预测下一个交易日的下跌风险强度 |
| **目标变量** | `risk = max(0, -next_return)`，只关注下跌方向 |

### 特征筛选

从全部数值列中，按关键词自动筛选冲击相关特征：
`ovx, vix, hy, spread, credit, risk, panic, stress, sentiment, news, gpr, diff, delta, change, return, vol`

### 超参数

| 参数 | 值 |
|------|-----|
| n_estimators | 600 |
| max_depth | 4 |
| learning_rate | 0.03 |
| subsample | 0.8 |
| colsample_bytree | 0.8 |
| reg_lambda | 1.0 |
| min_child_weight | 5 |

### 评估方式

- **TimeSeriesSplit** 5折交叉验证
- **Spearman 相关系数**：衡量排序能力
- **Top10% 冲击命中率 & Lift**：预测风险最高的 10% 样本中，实际发生冲击（跌幅≥2%）的比例 vs 基准比例

## 第2层：Ridge 元学习器

| 项目 | 说明 |
|------|------|
| **文件** | `stacking最终.py` |
| **模型权重** | `meta_ridge_model.pkl` |
| **任务** | 融合双专家信号与市场状态，预测 5 日涨跌幅 |

### 输入特征 (9维)

| 维度 | 特征 | 来源 |
|------|------|------|
| 1-7 | VIX、OVX、美债10Y收益率、美元指数、新闻情感、地缘政治评分、标普500 | 原始数据 |
| 8 | `lstm_impl_return` | LSTM 预测价格转隐含收益率 |
| 9 | `xgb_risk` | XGBoost 下跌风险得分 |

### 训练流程

1. StandardScaler 标准化
2. Alpha 网格搜索：`[1e-4, 1e-3, 0.01, 0.1, 1, 10, 100]`，验证集 MAE 选优
3. 训练集+验证集合并重训最终模型

### 风险区间划分

| 区间 | 条件 | 含义 |
|------|------|------|
| 高风险 | 预测收益率 ≤ P25 阈值 | 模型认为未来5日下跌概率较大 |
| 中风险 | P25 < 预测收益率 < P75 | 方向不明确 |
| 低风险 | 预测收益率 ≥ P75 阈值 | 模型认为未来5日上涨概率较大 |

## 集成引擎

| 项目 | 说明 |
|------|------|
| **文件** | `OilRisk_Engine.py` |
| **类** | `OilRiskSystem` |
| **入口方法** | `predict_today(df_raw)` → JSON |

### 调用链

```python
LSTM.predict_latest()  →  lstm_impl_return
XGBoost.predict()      →  xgb_risk_score
predict_one_step()     →  pred_return_pct, risk_zone
```

### 风险评分公式

```
risk_score = clamp(50 - pred_return_pct × 10, 0, 100)
```

- 预测收益率为正（看涨）→ 评分 < 50 → 低风险
- 预测收益率为负（看跌）→ 评分 > 50 → 高风险

### 输出 JSON 结构

```json
{
  "status": "success",
  "dashboard": {
    "score": 62.5,           // 风险评分 0-100
    "level": "中风险🟡"       // 高风险🔴 / 中风险🟡 / 低风险🟢
  },
  "expert_signals": {
    "lstm_impl_return": "-1.25%",   // LSTM 隐含收益率
    "lstm_direction": "下跌↓",      // 涨跌方向
    "xgb_risk_score": 0.0183        // XGBoost 风险值
  },
  "top_factors": [                  // XGBoost Gain Top5 归因因子
    {"name": "OVX_diff_5d", "value": 128.5},
    ...
  ],
  "prediction": {
    "predicted_return_pct": -1.25   // 元学习器预测收益率(%)
  }
}
```

## 数据概览

- **时间跨度**：约 38 年日频数据
- **核心数据源**：WTI/Brent 期货价格、OPEC 产量（按国家）、美国库欣库存、Baker Hughes 钻井数、CRB 指数、标普500、VIX/OVX、美债收益率、美元指数、PMI、消费者信心、通胀预期、新闻情感、地缘政治评分
- **数据处理**：月频变量通过月度差分转为变化量，日频缺失值前向填充

## 评估指标体系

| 指标 | 含义 | 适用模型 |
|------|------|----------|
| RMSE / MAE (%) | 预测收益率误差 | 三模型对比 |
| Spearman 相关系数 | 排序能力 | 三模型对比 |
| 方向准确率 | 涨跌方向判断正确率 | 三模型对比 |
| Top10%/20% 命中率 & Lift | 极端下跌预警能力 | 三模型对比 |
| 策略夏普比率 | 风险调整后收益 | Meta-Ridge |
| MAPE | 价格预测百分比误差 | LSTM |
